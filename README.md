# Skill grátis do Claude — histórias animadas

Uma skill antiga nossa (v1, novembro/2026) para o Claude planejar e montar Shorts de histórias animadas:
tema e título, roteiro, plano de cenas, narração, revisão e entrega.

## Como instalar

**No claude.ai:** baixe o `.zip` em *Releases* (à direita) → Configurações → Capacidades → Skills → enviar o zip.

**No Claude Code:** copie a pasta `make-cartoon-story-short/` para `~/.claude/skills/` e chame `/make-cartoon-story-short`.

A skill foi escrita para o nosso próprio projeto (three.js + Remotion), então os caminhos de pastas e scripts citados
nela são os nossos — use como guia e adapte ao seu.
